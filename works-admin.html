تسجيل الدخول

أدخل مفتاح GitHub (نفس المفتاح المستخدم في إدارة الطلبات). يُحفظ على هذا الجهاز فقط.

كيف أحصل على المفتاح؟
  1. من حساب alsanad-print على GitHub افتح Settings ← Developer settings ← Personal access tokens ← Fine-grained tokens.
  2. Generate new token ← في Repository access اختر مستودع الموقع فقط.
  3. في Permissions اجعل Contents على Read and write، ثم انسخ المفتاح والصقه هنا.
